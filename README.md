# Free nodes subscription

Public free proxy nodes aggregated from public sources, refreshed every 4 hours by GitHub Actions.

- sub.txt — base64 subscription (v2rayNG / v2rayN / Shadowrocket / Streisand)
- links.txt — plain share links
- clash.yaml — Clash Meta / Mihomo config (Clash Verge, FlClash, ClashMeta)

Free public nodes are unstable and short-lived. Do not use for sensitive accounts.
